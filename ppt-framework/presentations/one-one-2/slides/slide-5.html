Commitment 02 · Long-Term Asset

Knowledge Base Evaluation

Roadmap
WHY

Harness 的很多能力最终会被 LLM 与 AI IDE 吸收，但 knowledge base 是公司永恒的资产，值得长期投入。

V1

在 POC 基础上持续优化，尽早发布第一版并集成进 agent-teams，实现 knowledge base × code × test case 三方 cross check。先保证准确识别，再谈如何修复。

V2

引入 DeepEval 等开源工具，评估知识库在 agent-teams 实际使用过程中的召回率、准确率等指标，让效果可量化、可对比。

NEED

需 QA 团队支持，共同完成 Golden Dataset 的建立。
